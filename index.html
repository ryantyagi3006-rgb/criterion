The pipeline

One upload, a whole assessment

A teacher drops in a task sheet. Everything below happens without manual setup, and the teacher reviews all of it before anything reaches a student.

1

Read

PDFs, Word files, images and scans. Pages are rasterised for layout and the embedded text layer is used for exact wording.

2

Map

Every question is tied to the MYP criteria and strands it assesses, with marks, topic, difficulty and estimated time.

3

Equip

Calculators, formula sheets, code consoles and drawing canvases appear only on the questions that need them.

4

Mark

Answers are marked against the task-specific clarification, with feedback per criterion. Teachers moderate before release.

Criteria A to D

Built around how MYP is actually assessed

All eight subject groups are modelled, each with its own criterion names. A question can assess several criteria at once, which most tasks do. Shown here for Mathematics.

In the product

What students and teachers get

A calm workspace

Question navigator, autosave, countdown with auto-submit, flagging, keyboard shortcuts, zoom and full screen, in light or dark.

Seven answer formats

Multiple choice, short and extended writing, maths working with a symbol palette, a runnable code console, a drawing canvas and data tables.

Source texts and video

Long unseen extracts are carried across with the questions that reference them, and linked YouTube clips are embedded inline.

Diagrams preserved

Figures are cropped straight out of the original page, so graphs and labelled drawings survive the conversion intact.

Teacher control

Every classification, rubric and mark is editable. Nothing reaches a student until it is approved and released.

Criterion analytics

Achievement per criterion and subject group, with indicative levels out of eight from the marks earned.

About this page

This is a preview, not the app

GitHub Pages can only serve static files. The working platform needs a Node server for sign-in, uploads and marking, a Postgres database, and a private API key that must never be sent to a browser. None of that can run here, so this page is a showcase of the interface and the source.

The full application is deployed separately on Vercel. Everything you see described above is implemented in the repository linked at the top.

Criterion. Built with Next.js, Prisma, Postgres and Gemini Flash. Not affiliated with or endorsed by the International Baccalaureate Organization.
